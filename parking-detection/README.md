### \# 🚗 Parking Spot Detection App

### 

### \[!\[Streamlit App](https://static.streamlit.io/badges/streamlit\_badge\_black\_white.svg)](https://parking-detection.streamlit.app)

### 

### An AI-powered web application for detecting parking spot occupancy using computer vision and machine learning.

### 

### \## ✨ Features

### 

### \- \*\*Real-time Prediction\*\*: Upload parking spot images and get instant occupancy predictions

### \- \*\*Background Subtraction\*\*: Advanced feature extraction using custom background subtraction

### \- \*\*Lighting Adjustment\*\*: Adjust for different lighting conditions (day, night, dusk, etc.)

### \- \*\*Threshold Control\*\*: Fine-tune classification threshold for optimal accuracy

### \- \*\*Visual Analytics\*\*: Interactive visualizations of predictions and features

### \- \*\*Batch Processing\*\*: Analyze multiple spots or entire parking lots

### \- \*\*Export Results\*\*: Download predictions as CSV or JSON

### 

### \## 🚀 Live Demo

### 

### Visit the live app: \[https://parking-detection.streamlit.app](https://parking-detection.streamlit.app)

### 

### \## 🛠️ How It Works

### 

### 1\. \*\*Feature Extraction\*\*: Uses background subtraction to extract 13 handcrafted features

### 2\. \*\*Model Prediction\*\*: SVM classifier makes occupancy predictions

### 3\. \*\*Lighting Adjustment\*\*: Adapts to different lighting conditions

### 4\. \*\*Visualization\*\*: Shows feature extraction process and confidence scores
